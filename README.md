# Next Level Sales · sitio web

Landing page estática responsive para la consultoría externa especializada en ventas.

## Archivos

- `index.html` — estructura y contenido
- `styles.css` — sistema visual y responsive layout
- `script.js` — menú móvil, año dinámico y feedback del formulario demo

## Publicar en GitHub Pages

1. En el repositorio, abre **Settings → Pages**.
2. En **Source**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub genere la URL pública.

El formulario es demostrativo: está listo para conectar con correo, CRM o una herramienta de formularios cuando exista el endpoint real.

## Contenido de referencia

La propuesta se basa en el documento proporcionado “IDEA JOSHUA 2”. Los precios y el proceso de cuatro fases se mantienen tal como aparecen en ese material. La identidad visual, la arquitectura web y el copy de interfaz son una propuesta conceptual.
